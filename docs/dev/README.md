# 开发文档索引（docs/dev）

给接手/协助本项目的人（含 AI 助手）。**推荐阅读顺序**：

1. 根目录 [`AGENTS.md`](../../AGENTS.md) —— 铁律（技术选型、样式来源、API 结构、测试要求）、常用命令、代码地图、已知坑。开工前必读。
2. [`架构与代码地图.md`](./架构与代码地图.md) —— 当前代码实际长什么样：运行拓扑、目录结构、请求链路、鉴权设计、路由守卫矩阵、样式体系、**扩展指引（怎么加一个接口/页面）**、测试基础设施。
3. [`开发约定.md`](./开发约定.md) —— 命名与数据格式、TypeScript、文件组织、API 设计、CSS、组件、测试、Git、文档规范，以及待补项（ESLint 等）。
4. [`进度与交接.md`](./进度与交接.md) —— 里程碑与需求编号维度的状态、本轮交付物、**可复现的验证记录**、特意留白清单、下一步（含具体文件与开工要点）、交接自检清单。
