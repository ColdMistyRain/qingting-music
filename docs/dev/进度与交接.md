### 1.1 界面决策记录（2026-09-30，需求方裁决）
> 用户原话：“不需要完全按照原型里面的来，要按照我的感受来”、“我们的目的是把软件做的美观好看易用”。

**优先级：美观 + 易用 > 原型一致性。** `docs/design/mockup/` 降级为参考与素材库（提供令牌、配方、视觉语言），改样式不必先改原型；但必须保持单一视觉语言，并把改动回写原型 + 本文/PRD 决策记录，免得后人照旧原型改回去。

4. 本地文件接入：`<input type="file" multiple accept="audio/*">` + 拖拽（`dataTransfer.items` 展开文件夹，`webkitGetAsEntry` 递归）；`URL.createObjectURL` 生成 `Track.url`；卸载/清空时 `revokeObjectURL`。
5. 播放状态持久化（PL-07）：`localStorage` 存曲目标识 + 进度；**本地 Blob URL 刷新即失效**——刷新后只能恢复"服务器/在线"曲目，本地曲目恢复为"缺失"占位（可参考 PRD 对本地入歌单的"占位引用"思路）。
6. 异常处理（PL-09）：`audio.onerror` → 提示 + 自动跳下一曲；在线/服务器曲目失败同样走这条。
7. `PlayerBar.vue` 改为受 store 驱动；`LocalView.vue` 列表接 `SongRow`（建议现在就把行组件抽出来，音乐库与控制台复用）。
8. 注意：**iOS 首播必须由用户手势触发**（PRD 4.2），不要在任何 `onMounted` 里自动 `play()`。
